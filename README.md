# File Browser for CasaOS

This repository bootstraps a **File Browser** app setup intended for CasaOS deployments.

## What this includes

- A minimal project scaffold for tracking CasaOS-specific File Browser configuration.
- Room to add `docker-compose.yml`, icon assets, and CasaOS app metadata.

## Next suggested steps

1. Add a `docker-compose.yml` for the File Browser container.
2. Add CasaOS app metadata (`app.yml`) if publishing to an app store source.
3. Document bind mounts and symlink behavior required by your setup.
